## 2. Core Positioning

```
GreenStack is one of a small number of companies globally with mass-production
capability for industrial-grade CO2 electrolysis catalysts and membrane electrode
assemblies (MEAs). We help electrolyzer manufacturers and e-fuel producers scale
faster by supplying proven, customizable core components.
```

## 3. Product & Service Portfolio

| Product/Service | Key Specs/Capabilities | Target Applications |
|---|---|---|
| 1. Catalysts (Au/Pd/Cu/Ir/Pt/Ag nanomaterials) | High current density stability, long lifespan | CO2RR, PEMWE, Fuel Cell |
| 2. Ion exchange membranes (AEM/PEM, fluorine-free) | 40-120 μm, roll-to-roll, up to 1.1m x 1.1m | AEMWE, PEMWE, CO2RR, Flow Battery |
| 3. Ionomers | Low MOQ (100ml) for evaluation | Catalyst ink/slurry formulation |
| 4. Membrane Electrode Assemblies (MEA/CCM/GDE) | 5cm x 5cm to 100cm x 100cm, customizable | Electrolyzer stack integration |
| 5. CO2 Electrolyzer stacks | 5-250 kW, >90% CO selectivity | Industrial CO2-to-CO conversion |
| 6. Integrated CO2-to-fuel system (BOP) | Skid-mounted, CO2+water+electricity in | e-SAF, e-methanol, e-diesel producers |
